C. 规划文件双状态模型（V2.8新增）

规划类信息不得只用“已发布/未发布”一个状态。必须至少拆成：

【编制状态】：目录列入 / 调研编制中 / 已形成成果或草案 / 已审议通过 / 已正式成文 / 未知。

【公开状态】：未发现公开 / 起草说明或决策草案公开 / 正文公开但正式性待核 / 正式印发公开。

强制规则：

“未发现正式公开文本” ≠ “尚未编制完成”。

重大行政决策目录中的“计划完成时间” ≠ “公开发布日期”。超过目录计划时间但未见正文时，只能写“公开状态未确认/未发现正式公开文本”，除非官方明确说明延期，否则不得直接写“规划已延期”。

只有找到正式通知、文号、正式正文或能够证明正式生效的政府文件，才能写“正式印发”。

名称相近不得自动等同。例如《数字静安“十五五”专项规划》 ≠ 《静安区数据智能产业发展“十五五”规划》。

0.6 事实生命周期

所有事实分为五类：

【当前有效】：可直接回答“现在是什么状态”。

【历史节点】：解释项目如何走到今天，不得覆盖当前状态。

【已被后续事实替代】：保留历史价值，但回答现状时禁止使用。

【未来计划】：尚未发生，到期必须复核。

【待核实】：存在来源冲突、空间关系不清或仅有非官方线索，不得写成定论。

0.9 到期计划节点自动复核规则

适用范围说明：本规则适用于三乐、三林、S4/外环/嘉闵线、静安十五五等长期专项；不适用于第五部分“上海市重大项目动态”滚动新闻专题。

出现以下词语时必须建立“到期复核”：计划、预计、力争、拟、目标、争取、年底、上半年、下半年、本周内、某月建成/开放/通车。

到期后只允许出现三种更新：

【已完成】找到A级或可靠官方发布；

【延期/调整】找到官方新计划或解释；

【到期未确认】没有找到完成证据，必须写“截至本次查询未确认完成”，不得继续沿用旧计划口径。

规划目录特别规则：若到期的是“计划完成时间”，但只缺正式公开文本，不得自动标成【延期】；应分别记录“编制状态待核/已有成果”和“公开状态未确认”。只有官方明确改变完成节点、延后编制或说明延期时，才使用【延期/调整】。

用户核心诉求：S20西段↔S4双向拥堵改善

本专题的最终目标不是只追踪“工程是否完工”，而是判断莘庄立交S20西段↔S4两个方向的常态化拥堵什么时候真正改善、改善到什么程度。

施工硬进度继续完整保留：桩基、墩柱、箱梁、桥面、匝道、辅道、交通设施、交通翻交、分段验收/开放都属于判断离实际改善还有多远的必要依据。

在施工进度之上，保留双向通行体验轨，分别判断：

S20西段 → S4：重点观察外环西段进入莘庄立交后转向S4的排队、匝道交织、排队是否回溢至S20西段主线，以及地区车辆分流效果。

S4 → S20西段：重点观察S4北向进入莘庄立交后转入S20西段方向的汇入冲突、匝道容量、排队是否回堵至S4主线，以及进入S20西段后的连续通行情况。

方向边界：本专项默认关注上述两条路径；若用户询问S20东段/徐浦方向↔S4等其他转换方向，必须单独检索和判断，不自动合并进本专项。

两个方向必须独立判断，不得默认同步改善。某一方向先开放新匝道、先完成交通翻交或先形成连续通行条件时，可出现不同体验等级。

官方拥堵机理与改善目标

上海市交通委已明确将莘庄立交描述为流量巨大、常态化拥堵的高快速路关键节点，并通过高快速路出入口、东西向辅道及立交本体优化，减少冗余交通、提升转换效率。

官方方案测算：莘庄立交总交通量相比现状可减少约10%。该指标是整个立交总交通量变化，不得写成“S20西段→S4或S4→S20西段拥堵下降10%”。

市、区交通体系同时推进S4入城段与外环西段提升，并规划贯通莘庄立交的辅道跨线桥；后续还将通过地区路网和地面辅路分担短途、到发交通。

闵行区交通部门公开口径进一步指出，未来S20外环西段抬升工程将与S4地面辅路互联互通，目标是分流莘庄立交通行压力、提升短途通行效率。对用户而言，这意味着真正决定体感改善的不是某一根梁，而是“外环高架 + 地面辅道 + S4地面辅路 + 匝道/地区道路”形成组合网络。

主体结构较早成型 ≠ 莘庄节点提前开放交通。 莘庄立交是外环西段的控制性节点之一，箱梁、桥面等主体结构可以早于全线完成，但只有与相邻高架、匝道、地面辅道及交通组织形成连续体系后，才可能产生完整交通功能。

当前没有官方依据确认莘庄立交会在2028年前独立整体开放。 若未来出现局部提前使用，必须以正式交通切换、分段开放或通车公告为准。
